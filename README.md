# Ucodes – Authentic Nigerian & African Delicacies Restaurant Template

A premier restaurant website template dedicated to authentic Nigerian delicacies, African food culture, and Nigerian master chefs. Features rich native menu items (Smoky Party Jollof Rice, Royal Egusi & Pounded Yam, Sizzling Beef Suya, Spicy Asun, Fisherman Seafood Okra Soup, Golden Puff-Puff), category filtering, interactive modal details, online reservation, food showcase gallery, and culinary stories.
